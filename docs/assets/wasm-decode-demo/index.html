ac3forge - WASM decode demo

A real AC-3/E-AC-3 decoder, compiled to WebAssembly and running entirely in this tab: no server-side decode, no upload. Load the bundled Atmos-in-DD+ stream below, or drop in your own .ec3/.ac3 elementary stream.

What's real here, and what isn't. The decode is real: this page runs ac3::forge's actual C++ AC-3/E-AC-3 decoder compiled to WASM, and every number shown - sample rate, channel layout, the audio you hear, the per-channel energy driving the dots below - comes out of that real decode. What this panel does not show is individual Atmos object positions: ac3::forge does not yet have a decode-side OAMD/JOC parser (it can write object metadata when encoding, but nothing in the library can read it back out of a stream today), so there is no real per-object position to visualize. The dots below are the real decoded 5.1 bed's per-speaker energy, using the same room/speaker model as the desktop GUI's SoundfieldView.qml - genuinely decoded, just not object-level. The audio you hear is a simple stereo downmix of that same real bed for playback on ordinary speakers/headphones.
Part of ac3forge, roadmap item F3. Source: examples/wasm_decode_demo/.
