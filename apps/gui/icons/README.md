# Generated

Every file in this directory except `ac3gui.rc.in` is generated by
[`assets/icon/generate_icons.py`](../../../assets/icon/generate_icons.py) from one procedural
mark. Don't hand-edit a `.ico`/`.icns`/`.png` here — change the drawing code in that script and
re-run it (`python assets/icon/generate_icons.py`), which also regenerates the Android and WASM
icon assets from the same source.

`ac3gui.rc.in` is a hand-authored build template (Windows resource script), not generated; it
just lives alongside the icons it references.
